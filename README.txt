Open index.html in your browser. Keep the src directory beside it.

index.html: page structure
src/styles.css: styles and entrance animation
src/theme.js: initial theme/language preferences
src/main.js: content and interactions
src/assets/: extracted original images and PDF resume

Images use object-fit: contain to show the full artwork without cropping.
Google Fonts requires internet; system fonts are used when offline.
